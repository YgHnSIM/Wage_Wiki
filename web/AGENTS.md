# WEB ASSETS KNOWLEDGE BASE

## OVERVIEW

`web/` contains the small client-side layer used by the generated GitHub Pages site.

## WHERE TO LOOK

- `assets/app.js`: browser interactions, filtering, and navigation behavior.
- `assets/styles.css`: site presentation and responsive layout.
- `assets/favicon.svg`: site icon.

## CONVENTIONS

- Keep the web layer compatible with static files generated by `scripts/build_site.py`.
- Validate JavaScript syntax with `node --check web/assets/app.js`.
- Verify changes through a local generated site and `scripts/check_site.py`; do not rely on source inspection alone.

## ANTI-PATTERNS

- Do not add server-side assumptions or runtime dependencies to the static site.
- Do not edit generated HTML under `build/site/` as a source change.
- Do not break the repository-base-path behavior used by GitHub Pages.
