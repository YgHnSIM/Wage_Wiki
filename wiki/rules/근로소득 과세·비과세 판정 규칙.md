# 근로소득 과세·비과세 판정 규칙

## Issue

사용자가 지급한 금품·경제적 이익·비용 상환액 중 무엇이 근로소득이고, 그중 어느 부분이 소득세법 제12조의 비과세 항목인지 판정한다. 근로기준법상 임금인지와 소득세법상 근로소득인지는 목적과 요건이 다르므로 한 영역의 결론을 다른 영역에 그대로 적용하지 않는다.

## Rule

급여대장 명칭이 아니라 실제 지급 원인과 수령자가 얻은 경제적 이익을 먼저 확정한다. 고용관계에서 받은 경제적 이익이 근로소득에 들어가면 과세가 원칙이고, 소득세법 제12조와 시행령이 정한 항목·대상자·지급방식·시점·한도를 모두 충족한 부분만 비과세한다. 한도를 넘거나 하나의 요건이라도 빠진 금액은 과세 근로소득으로 분리한다. ^income-tax-rule

## Application Order

1. **지급 사실 확정:** 지급자·수령자·귀속월·지급원인·현금화 가능성·반환의무를 급여규정과 전표로 확정한다.
2. **소득 구분:** 근로소득, 퇴직소득, 기타소득, 회사 업무비의 직접 지출 또는 실비변상적 급여를 구별한다.
3. **법정 항목 매칭:** 소득세법 제12조의 어느 목을 적용하는지 지정한다. “복지비” 같은 포괄 코드를 근거로 삼지 않는다.
4. **구성요건 확인:** 식사 제공 여부, 차량 소유·임차와 직접 운전, 출장 여비 중복, 자녀의 기준일 나이, 생산직 직종과 두 급여 문턱 등 항목별 사실을 확인한다.
5. **한도 계산:** 월 한도는 해당 월별로, 연 한도는 과세기간 누계로 계산한다. 미사용 한도는 다른 달·다른 항목·다른 근로자에게 이월하거나 전용하지 않는다.
6. **독립 판정:** 비과세액을 확정한 뒤 국민연금, 건강·장기요양, 고용·산재보험의 제외·재산입 규칙을 각각 적용한다. ^income-tax-classification-sequence

## Item Tests

| 항목 | 필수 사실 | 2026-07-25 한도·경계 |
|---|---|---|
| 현금 식대 | 근로자가 사내 급식·식권 등 식사를 제공받지 않음 | 월 20만 원, 초과분 과세 |
| 자가운전보조금 | 본인 소유·본인 명의 임차 차량, 직접 운전, 업무 사용, 실제 시내 출장 여비 미수령, 사내 기준 | 월 20만 원, 요건 미충족 시 전액 과세 위험 |
| 보육급여 | 근로자 또는 배우자의 자녀, 과세 기간 개시일 기준 6세 이하, 보육 관련 지급 | 자녀 1명당 월 20만 원 |
| 생산직 초과근로급여 | 시행령·시행규칙상 직종, 월 정액 급여 260만 원 이하, 직전 총급여 3,700만 원 이하, 실제 법정 초과근로급여 | 원칙적으로 연 240만 원 |
| 실비 여비 | 업무상 출장, 회사 기준, 실제 지출 또는 사회통념상 실비변상 정도와 대응 | 정액 한도가 아니라 실비변상성으로 판단 |
| 직무발명보상금 | 법정 직무발명, 적격 지급자·수령자, 특수관계 제외, 귀속 소득 구분 | 연 700만 원 |

식대 20만 원을 받고 구내식당 식사까지 제공받으면 현금 식대는 러목의 요건을 충족하지 않는다. 자가운전보조금 20만 원도 실제 시내 출장비를 별도로 정산받거나 차량이 본인 소유 또는 본인 명의 임차 차량이 아니면 같은 결론이다. 반면 업무 출장 영수증 68만 원을 정산한 경우에는 월 20만 원 정액 한도를 적용하는 것이 아니라 지급액 전부가 실비 변상 정도인지 판단한다. ^income-tax-item-tests

## Numerical Control

월 급여에서 식대 25만 원, 적격 자가운전보조금 20만 원, 적격 자녀 2명에 대한 보육급여 40만 원을 지급했다고 가정한다. 식사를 제공하지 않고 차량 요건과 자녀 요건을 모두 충족하면 비과세 후보액은 식대 20만 원 + 차량 20만 원 + 보육 40만 원 = 80만 원이고, 식대 초과분 5만 원은 과세한다. 이 계산은 각 항목의 한도를 따로 적용한 결과이지, 총 85만 원 중 임의로 80만 원을 비과세한 것이 아니다.

생산직 급여는 월별 자격 판정과 연 누계가 겹친다. 월 정액 급여 260만 원, 직전 총급여 3,700만 원은 금액 문턱을 통과하지만 1원이라도 넘으면 통과하지 않는다. 이번 달 초과근로급여가 70만 5천 원이고 직전까지 비과세 누계가 200만 원이면 이번 달 비과세는 40만 원, 과세는 30만 5천 원이다.

## Temporal and Authority Rule

급여 귀속일에 시행되는 법률·시행령을 적용한다. 2026-02-27부터 생산직 문턱은 월 정액 급여 260만 원과 총급여 3,700만 원으로 확대되었다. 국세청 웹 안내처럼 현행 수치 반영이 늦은 설명자료가 있으면 권위 1의 현행 법령을 우선하고, 안내자료의 계산 사례는 구조를 이해하는 참고자료로만 사용한다. ^income-tax-temporal-priority

## Payroll, Withholding and Reconciliation

- 급여코드는 최소한 `taxable`, `nontax_article`, `cap_unit`, `eligible_from`, `eligible_to`, `evidence_key`를 갖게 한다.
- 월 원천징수 대사에서는 총지급액 = 과세 근로소득 + 항목별 비과세액 + 근로소득 외 지급액이 되는지 확인한다.
- 근로소득 지급명세서의 비과세 코드·금액을 급여대장과 맞추고, 생산직 수당과 직무발명보상금은 연 누계를 별도 대사한다.
- 사회보험 신고용 보수는 “세법상 비과세”만으로 자동 제외하지 않고 각 보험 Rule의 예외를 다시 확인한다.

## Exceptions and Failure Modes

- 영수증이 있다는 사실만으로 개인 소비나 과다 지급액이 실비가 되지는 않는다.
- 정기·일률적으로 지급된다는 이유만으로 비과세가 부정되지는 않지만, 지급 구조가 법정 요건과 맞지 않으면 과세한다.
- 월 한도 미달액을 다음 달로 넘기거나, 식대 한도의 잔액을 차량·보육급여에 더하지 않는다.
- 국세청 안내·급여프로그램 기본값이 현행 법령보다 늦게 갱신될 수 있으므로 시행일과 버전을 기록한다.

## Conclusion

근로소득 비과세는 명칭 중심의 예외 처리가 아니라 법정 항목별 구성요건과 계산 단위를 적용하는 제한 규칙이다. 결론에는 적용 조문, 대상 사실, 계산식, 귀속기간, 증빙과 재검토 트리거를 남겨 제3자가 같은 결과를 재현할 수 있어야 한다.
