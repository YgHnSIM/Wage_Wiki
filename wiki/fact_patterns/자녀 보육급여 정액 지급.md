# 자녀 보육급여 정액 지급

## 전형 사실과 쟁점

회사는 급여 규정에 따라 과세 기간 개시일인 2026-01-01 현재 각각 3세와 6세인 자녀 두 명을 둔 근로자에게 자녀별 월 20만 원, 합계 40만 원의 보육급여를 지급한다. 실제 어린이집 지출 증빙은 요구하지 않으며, 자녀 요건을 충족하는 동안 매월 정액을 지급한다. 2026년부터 세법상 한도가 `근로자별 월 20만 원`이 아니라 `해당 자녀 1명당 월 20만 원`으로 바뀌었으므로, 과거 급여 프로그램의 가구 단위 한도를 그대로 사용하면 과세액이 잘못된다. ^childcare-2026-transition

## 판정 전 확인할 사실

- 근로자 본인 또는 배우자의 자녀인가.
- 해당 과세기간 개시일 기준으로 각 자녀가 6세 이하인가.
- 자녀 식별값별 지급액과 월 20만 원 한도를 관리하는가.
- 근로자와 배우자의 각 근무처 지급 여부를 사실자료로 보존했는가.
- 지급이 자녀별 정액인지 실제 보육비 정산인지.
- 취업규칙·급여 규정상 지급 의무, 중단 조건과 휴직 처리 방식이 무엇인가.

## 9축 판정

| 영역 | 기본 결론 | 확인 포인트 |
|---|---|---|
| 임금 | 조건부 포함 | 규정상 정기적 지급 의무와 복지 비용 정산 여부 |
| 통상임금 | 대체로 조건부·제외 가능 | 자녀 보유라는 개인 조건과 소정근로 대가성 |
| 평균임금 | 임금이면 포함 | 산정기간에 귀속된 실제 지급액 |
| 최저임금 | 임금이면 산입 검토 | 월 현금급여와 현행 제외항목 여부 |
| 근로소득세 | 40만 원 비과세 가능 | 2026년 자녀 1명당 월 20만 원과 연령 기준일 |
| 국민연금 | 적격 40만 원 제외 후보 | 비과세 근로소득과 재산입 예외 |
| 건강·장기요양 | 적격 40만 원 제외 후보 | 건강보험 보수의 비과세 제외와 예외 |
| 고용보험 | 적격 40만 원 제외 후보 | 과세 근로소득과 보수 제외 규정 |
| 산재보험 | 적격 40만 원 제외 후보 | 같은 보수 기초와 산재보험 적용관계 |

## 수치 적용례

기본급 320만 원과 적격 자녀 두 명의 보육급여 40만 원을 지급하면 총지급액은 360만 원이다. 각 자녀에 대해 `min(20만 원, 20만 원)`을 적용하므로 비과세 후보는 40만 원, 과세 근로소득 후보는 320만 원이다. 한도는 가구 전체 20만 원을 한 번 적용하거나 두 자녀의 합계 40만 원에 다시 20만 원을 적용하지 않는다. ^childcare-tax-calculation

노동법상 임금성은 40만 원 전액을 대상으로 별도 판단한다. 회사 규정에 지급 의무가 있으면 임금성이 인정될 수 있지만, 자녀 보유라는 개인적 조건 때문에 통상임금의 일률성·소정근로 대가성은 별도 검토가 필요하다. 세법상 비과세라는 이유만으로 평균임금이나 최저임금 산입 결론을 그대로 적용하지 않는다.

## 반대 사실과 결론 변경

첫째 자녀가 2026-01-01 현재 7세이고 둘째만 6세라면 비과세 후보는 둘째 몫 20만 원뿐이다. 회사가 두 자녀에게 각각 20만 원을 지급해도 첫째 몫 20만 원은 과세 근로소득과 사회보험 보수 산입 후보가 된다. 반대로 2026-01-01 현재 6세였던 자녀가 연중 생일을 지나 7세가 되었다는 사실만으로 월별 연령 기준을 새로 적용하지 않고 법정 기준일을 따른다.

근로자와 배우자가 각 근무처에서 같은 자녀와 관련된 급여를 받는 경우에는 지급 사실을 숨기지 말고 수령자·사용자·자녀별로 기록한다. 이를 자동으로 부부 합산하거나 자동 배제하지 말고 해당 귀속연도의 법문과 원천징수 처리 기준을 확인한다. 실제 어린이집 비용만 회사가 직접 부담하는 구조라면 정액 보육급여와 다른 복리후생·비용부담 규정을 적용할 수 있다.

## 급여·세무·보험 대사

급여대장에는 자녀 식별키별로 `CHILDCARE_NTAX` 20만 원씩을 기록하고, 과세 기간 개시일의 가족관계와 나이를 스냅숏으로 보존한다. 총 지급액 360만 원과 회계 전표·이체액, 과세 근로소득 320만 원과 원천징수 대장, 보험별 산정 기초를 대사한다. 국세청 웹 안내는 2026-07-25 캡처에도 종전 `월 20만 원` 설명을 남기고 있으므로, 화면 문구보다 현행 소득세법과 시행일을 우선한다. ^childcare-source-version-control

- 과세기간 개시일 기준 가족관계·자녀 연령 자료
- 근로자 신청서와 자녀별 지급명세
- 배우자 근무처의 지급 여부 확인자료
- 취업규칙·급여규정과 중단조건
- 급여대장, 자녀별 월 한도대장과 원천징수대장
- 국민연금·건강·고용·산재 신고 대사표

## 흔한 오류

- 2026년에도 근로자 또는 가구별 월 20만 원만 적용한다.
- 지급월 말의 나이를 보고 매월 자격을 바꾼다.
- 자녀 식별값 없이 총액 코드 하나만 사용한다.
- 국세청 웹 안내의 종전 수치를 현행 법률보다 우선한다.
- 세법상 비과세를 근거로 노동법상 비임금이라고 단정한다.

## 결론

정기적 보육급여는 지급 의무와 지급 구조에 따라 노동법상 임금일 수 있다. 2026년 소득세 비과세는 과세 기간 개시일 기준 6세 이하인 적격 자녀 1명당 월 20만 원까지 적용한다. 자녀별 한도, 과세 초과액과 보험별 산정 기초를 분리해 관리해야 한다. ^fact-conclusion
